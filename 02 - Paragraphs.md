Pressing Enter once inside a paragraph usually does not create a visible line break. The following two lines are treated as part of the same paragraph:

This is the first line.
This is the second line.

In contrast, a blank line separates the text into two paragraphs:

This is the first line.

This is the second line.

You can also create a line break without starting a new paragraph. One option is to add two spaces at the end of the first line:

This is the first line.  
This is the second line.

Another option is to end the first line with a backslash (`\`):

This is the first line.\
This is the second line.

You can also use the HTML `<br>` tag:

> **Compatibility:** Embedded HTML.

This is the first line.<br>
This is the second line.
