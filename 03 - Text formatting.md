Markdown can highlight parts of the text by using different characters.

# Basic formatting

Two asterisks show the text in **bold**.

Two underscores also show the text in __bold__.

One asterisk shows the text in *italics*.

One underscore also shows the text in _italics_.

Three asterisks show the text in ***bold and italics***.

Three underscores also show the text in ___bold and italics___.

# Highlighted text

The `<mark>` tag shows <mark>highlighted text</mark>.

> **Compatibility:** Embedded HTML. It may not work in renderers that block HTML.

# Strikethrough

Two tildes show ~~strikethrough text~~.

> **Compatibility:** GFM extension.

# Footnotes

References such as `[^1]` add footnotes to the text, as shown in the following example:

Markdown[^1] is a lightweight markup language used to format[^2] text.

[^1]: Text for the first footnote.
[^2]: Text for the second footnote.

> **Compatibility:** Supported by GitHub and some other renderers; it is not part of basic Markdown.
