# Unordered lists

The `*`, `-`, and `+` symbols can be used as markers for an unordered list:

* Item created with an asterisk
- Item created with a hyphen
+ Item created with a plus sign

To keep a consistent style, you usually choose one marker. The following example uses `-` and adds nested items with indentation:

- First item
- Second item
  - Nested item
  - Another nested item
- Third item

# Ordered lists

Numbers followed by a period create an ordered list:

1. First step
2. Second step
3. Third step

# Task lists

Brackets can represent completed and pending tasks:

- [x] Completed task
- [ ] Pending task

> **Compatibility:** GFM extension.
