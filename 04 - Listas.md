## Listas desordenadas

Los símbolos `*`, `-` y `+` pueden utilizarse como marcadores de una lista desordenada:

* Elemento creado con asterisco
- Elemento creado con guion
+ Elemento creado con signo más

Para mantener un estilo uniforme, normalmente se elige un único marcador. En el siguiente ejemplo se utiliza `-` y se agregan subelementos mediante sangría:

- Primer elemento
- Segundo elemento
  - Subelemento
  - Otro subelemento
- Tercer elemento

## Listas ordenadas

Los números seguidos de un punto crean una lista ordenada:

1. Primer paso
2. Segundo paso
3. Tercer paso

## Listas de tareas

Los corchetes permiten representar tareas completadas y pendientes:

- [x] Tarea completada
- [ ] Tarea pendiente

> **Compatibilidad:** extensión de GFM.
