The `|` characters separate columns, and a row of hyphens separates the headers from the content.

> **Compatibility:** Tables are a widely supported GFM extension, but they are not part of basic Markdown.

The following table uses the default alignment:

| Syntax | Output | Use |
|--------|--------|-----|
| `**text**` | **text** | Bold |
| `*text*` | *text* | Italics |
| `[Google](https://google.com)` | [Google](https://google.com) | Links |
| `` `code` `` | `code` | Code |

Colons in the separator row can align a column to the left, center, or right:

| Left | Center | Right |
|:-----|:------:|------:|
| Text | Text | Text |
| Other text | Other text | Other text |
