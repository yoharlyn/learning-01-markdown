To add headings, write one to six `#` symbols. More symbols create a less prominent heading.

One `#` symbol creates a level 1 heading:

# Heading 1

Two `##` symbols create a level 2 heading:

## Heading 2

Three `###` symbols create a level 3 heading:

### Heading 3

Four `####` symbols create a level 4 heading:

#### Heading 4

Five `#####` symbols create a level 5 heading:

##### Heading 5

Six `######` symbols create a level 6 heading:

###### Heading 6
